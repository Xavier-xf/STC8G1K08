## 电气前提

| 引脚 | 功能与要求 |
|---|---|
| P5.4 / Pin1 | CPU_CHECK通信与心跳；普通GPIO/INT2下降沿，不配置为外部RST；低拉、高阻释放，需要外部上拉 |
| P5.5 / Pin3 | 推挽复位控制；正常低、复位高约200 ms、随后低，不改为开漏 |
| P3.0 / RxD | 下载接口接收，按STC-ISP所需接线 |
| P3.1 / TxD | 下载发送及运行诊断输出；9600、8N1 |
| VCC / GND | 核对实物供电及公共地；通信与下载接口电压须兼容器件 |

双端开漏只用于CPU_CHECK通信线，不用于P5.5。主机和STC的引脚模式、电压、串联电阻、上拉与线电容须匹配；功能应答成功不等于电气裕量已测量。上升沿、高低门限和掉电状态另做板级检查，不仅用万用表判断2 ms脉冲。

P5.5保证从GPIO初始化后进入正常电平；STC复位、下载及掉电期间的引脚默认状态由芯片和外部电路决定，不承诺软件能够控制尚未运行时的输出。

## ISP 配置

| 选项 | 本固件要求 |
|---|---|
| IRC/SYSCLK | 24 MHz，必须与MAIN_FOSC一致；其他频率需适配Timer0与UART重载后重新构建 |
| P54RST | 0，P5.4为普通GPIO |
| 硬件WDT自动启动 | 使用此前验证配置：关闭，由app_init启用内部WDT |
| 低压复位、复位延时 | 沿用已验证实板配置，记录实际选项；本次没有测定或变更这些选项 |
| 代码保护 | 按接收方交付策略明确记录；不在未授权情况下改动 |

串口为TX-only诊断；不是UART命令接口。协议命令通过P5.4进行。STC内部WDT不会随STOP关闭。

## 烧录与检查

1. 确认工程、器件、频率及HEX版本；需要时用 `sha256sum` 或Windows `Get-FileHash -Algorithm SHA256` 对照交付清单。
2. 按STC-ISP提示下载，使用测试板及已验证的电源/复位接线，避免下载状态影响正在工作的目标设备。
3. 确认横幅版本、`protocol=short-frame 3/5 bytes`、`P55=LOW power-on, HIGH reset`及30秒宽限/5秒超时/200 ms脉冲。
4. 冷启动默认stopped；主机初始化发送心跳后，START命令执行进入startup，越过宽限后进入monitoring。
5. 按 [验证记录](verification.md) 检查命令确认、STOP暂停、无心跳复位及重启恢复。记录实际电气测试和未测项，不用早期P5.5高阻检查表。
