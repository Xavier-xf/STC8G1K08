# STC8G1K08 RESET Firmware Implementation Plan

> Use the executing-plans workflow for this plan. Keep SMOKE and MONITOR unchanged.

**Goal:** Add one-shot external reset control and STC internal WDT protection in a separate Keil project.

**Architecture:** A pure `reset_controller` state module decides when a timeout becomes one 200 ms assertion pulse and waits for heartbeat recovery. `Reset.c` owns Timer0, INT2, UART1, P5.5 high-Z/drive transitions, and WDT_CONTR servicing.

### Task 1: Reset state machine test

**Files:** `firmware/reset_controller_test.c`, `firmware/run_reset_controller_test.sh`, `firmware/Driver/inc/reset_controller.h`, `firmware/Driver/src/reset_controller.c`

- [ ] Write tests for startup, timeout assertion, pulse completion, wait-for-recovery, repeated reset, and rollover.
- [ ] Run the host test before the module exists and observe the expected compile failure.
- [ ] Implement the smallest pure state machine.
- [ ] Run the host test and require a passing result.

### Task 2: RESET Keil project

**Files:** `firmware/User/Reset.c`, `firmware/RVMDK/STC8G1K08-RESET.uvproj`, `firmware/User/Config.h`, `firmware/Driver/inc/stc8g1k08_regs.h`

- [ ] Add compile-time reset polarity, pulse, WDT divisor, and WDT enable/clear definitions.
- [ ] Configure P5.5 input-only except during RESET_ASSERT; configure P5.4 INT2 and Timer0 as in MONITOR.
- [ ] Start WDT with 128 divisor and clear it from the main loop.
- [ ] Add UART state diagnostics and repair XML closure before validation.
